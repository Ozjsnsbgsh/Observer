## 怎么读

- 建立框架：先读《政治学通识》《置身事内》。
- 对照历史：再读《叫魂》《血酬定律》《枪炮、病菌与钢铁》。
- 比较贫穷解释：对照《财富、贫穷与政治》与《工作、消费主义和新穷人》。
- 观察权力与传播：阅读《规训与惩罚》《娱乐至死》《狂热分子》。

每本书记录三个问题：作者的核心主张是什么？证据能支持到什么范围？有哪些反例或不同解释？
